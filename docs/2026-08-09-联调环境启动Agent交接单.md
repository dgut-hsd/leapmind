## 三、启动前检查

### 3.1 检查配置文件

确认以下文件存在，但不要打印内容：

```text

```

只检查以下变量是否有值：

```text

```

检查结果只能报告“已配置”或“未配置”，不能输出变量值。

### 3.2 安全加载根目录 `.env`

每个服务进程启动前，在对应 PowerShell 进程中执行以下逻辑。禁止在逻辑中加入输出变量值的语句。

```powershell
$envFile = "D:\code\HSDProjectWrokPlace\Leapmind\leapmind\.env"

Get-Content -LiteralPath $envFile | ForEach-Object {
  $line = $_.Trim()
  if ($line -and -not $line.StartsWith("#")) {
    $parts = $line -split "=", 2
    if ($parts.Count -eq 2) {
      Set-Item -Path "Env:$($parts[0].Trim())" -Value $parts[1].Trim()
    }
  }
}
```

根目录 `.env` 不会被三个项目自动共同加载，因此不能省略这一步。

### 3.3 检查端口

依次检查：

```text

6379  Redis
8000  Python 画像引擎
8080  Java 后端
5173  Vite 前端
```

若 `8000`、`8080` 或 `5173` 已被占用：

1. 先识别 PID 和进程名。
2. 若对应服务健康，复用现有服务。
3. 若不是目标服务，停止并向用户报告，不得擅自结束进程。

## 五、联调冒烟验证

### 5.1 登录

使用现有完整业务库中的测试账号通过前端登录。不要在报告中记录账号密码，只记录实际 `userId`。

若没有可登录账号，停止并请求用户提供测试账号或通过正式注册流程创建，不得直接修改密码字段。

### 5.2 M2 前端事件

执行一次请求讲解并等待 SSE 完成，然后点击一次讲解反馈。

预期：

```text
POST /api/user-profile/{userId}/record-event
request_explanation / M2
explanation_feedback / M2
```

### 5.3 M7 对话事件

完成一次 AI 对话 SSE 请求。

预期：

```text
POST /api/conversation/ask
ask_doubt / M7
```

`ask_doubt` 由 Java 对话后端发布。前端不应为同一次对话再调用 `/api/events/collect`。

### 5.4 M6 投影

投影周期约为 30 秒。完成事件操作后等待 30 至 60 秒，只读查询该用户最近事件：

```sql
SELECT id, event_id, event_type, source_module, user_id, kp_id, process_status, occurred_at
FROM user_events
WHERE user_id = :userId
ORDER BY id DESC
LIMIT 20;
```

再查询画像：

```sql
SELECT user_id, profile_version, profile_status, confidence,
       last_processed_event_id, computed_at
FROM user_profiles
WHERE user_id = :userId;
```

允许的正常结果：

- 画像已更新。
- `NO_CHANGE`，已有画像无需更新。
- 数据不足，暂时不能形成可靠画像。

不能仅以“画像数值没有变化”判断联调失败。应结合事件状态、Java 投影日志和 Python 响应判断。

## 七、常见问题处理

### Python 启动到 8001

说明根目录 `.env` 没有正确加载。重新确认进程环境中的 `PORT` 已配置，但不要输出其值，然后重启 Python。

### Java 报 MySQL Access denied

检查 `SPRING_DATASOURCE_USERNAME`、`SPRING_DATASOURCE_PASSWORD` 和数据库授权，只报告哪个变量或权限异常，不得输出密码。

### Java 无法调用画像引擎

依次检查：

1. Python `8000/health`。
2. `M6_PROFILE_ENGINE_BASE_URL` 是否已配置。
3. Java 日志中的 HTTP 状态和请求 ID。

### M7 对话失败

优先检查 Redis、Java 日志、对话接口和外部 AI 服务配置。不要为了绕过问题伪造前端 `ask_doubt` 事件。

### 事件一直是 PENDING

检查：

1. `M6_PROFILE_ENGINE_PROJECTION_ENABLED` 是否启用。
2. Java 和 Python 是否连接同一个数据库。
3. Python 画像接口是否返回成功。
4. Java 投影任务是否每约 30 秒执行。
